# Starport Market 玩法 v3 最终设计 —《暗涌夜市》修订合成版

实现契约。基底 =《暗涌夜市》竞标案，按评审团警告修复三处结构问题，嫁接《大启航前夜》《港口记得你》被一致推荐的机制。实现语言 GDScript，规则全部收敛在 `market_game.gd` + `content.json`，确定性 seed，四接口只扩字段不改形。

## 0. 设计支柱

一切收益先押代价——风险明码标价、可评估、可管理。赢是判断的奖赏；输的人能说出自己哪一步贪了。

## 1. v2 处置清单

**保留**：8 货品+tag、需求管线主干（基础×事件×客群偏好×价格弹性×声望×噪声±12%）、6 客群、13 事件（加风声元数据）、FIFO 批次保质期、确定性 stable_rng(label,day)、try_quote/try_step/observation/terminal_summary 四接口、18 夜（品牌线「十八夜。一个摊位。没有重来。」保留）。

**删除**：广告系统（5 campaigns + 背刺 roll）、里程碑赛中经济奖励（降级为纯徽章）、每夜随机执照二选一、悬赏自动结算、升级 neon_sign/rent_permit/bounty_scanner、loyalty_bias 字段。

**重构**：悬赏→契约制；执照→路线牌（夜1/7/13 三次不可逆二选一）；升级 7→4；声望→硬资源（契约门槛+大摆幅，需求系数 0.6%/点）；终夜→可备战的大离港夜；终局分→全程可见明账。

## 2. 机制总表

### 2.1 风声与行情（跨夜情报）
- 今晚事件确定可见；**明晚风声**：双候选事件+概率（如「彗星祭 65% / 静轨夜 35%」），真值 stable_rng 定；**后晚迷雾**：单个关键词小图标（如「甜」「官方」）。
- unit_cost 在事件系数外再乘确定性日行情波动 0.85–1.2（stable_rng("market:"+pid, day)）；货品行显示近 5 夜进价走势条（迷你 sparkline，UI 已有行卡可容纳）。
- 升级「情报天线」（2 级）：Lv1 明晚概率更准（显示值=真实概率），Lv2 后晚也显示双候选。
- 观测字段：`observation().rumors = { tomorrow: [{event_id, prob}], later_hint: "tag" }`。

### 2.2 契约看板（原悬赏）
每夜至多 2 张契约卡，规划期接受/放弃（放弃无成本）：
- **现货急单**：今晚交货。量 = 3 + 0.4×夜数 ± 2，单价 1.7× 基准价。交不足 → 罚合同额 30% + 声望 −4；履约 → 全款 + 声望 +2。
- **跨夜大单**（夜 5 起，需声望 ≥55）：2–3 夜后交 10–18 件，单价 2.0×，接单即收定金 30%。违约 → 退定金 ×1.5 + 声望 −8；履约 → 尾款 + 声望 +5 + **人情点 +1**。
- **终极大单**（夜 15 出现一次）：终夜交 ~20 件终夜主题品，单价 2.4×，定金 40%。违约 → 定金 ×2 + 声望 −12；履约 → 终局分 +150。
- 结算顺序：契约交付优先于散客（沿用 v2 悬赏优先结算代码路径）。
- 状态：`state.active_contracts = [{id, product_id, qty, unit_price, deposit, due_day, penalty_mult, rep_penalty, rep_reward, kind}]`。
- 升级「议价终端」（2 级）：契约单价 +8%/级。路线牌「码头中介」：契约价 +10% 且每夜多 1 张契约卡。

### 2.3 走私与热度（推运气核心）
- 每夜**走私舱**（右栏独立紧凑卡，非货品行内双列）：2–3 个货品 × 限量 6–10 件，价格 = 官方进价 ×0.55–0.65，每件 **热度 +2**。
- 热度 0–100 常驻可见，**百分比衰减**：每夜 −ceil(heat×0.22)（≥4 时至少 −4）。
- 查验概率 = clamp(heat × 事件系数, floor, 80)%，**floor = 6 + total_smuggled_units // 12**（累计走私越多，地板越高——无免费私货）。海关严查事件 ×2，节庆 ×0.6。**概率提前显示在计划面板**。
- 结算开始先判定查验（stable_rng("inspect", day)）：中查 → 没收全部走私批次（批次带 `hot: true` 标记）+ 罚款 $1×热度 + 声望 −5，热度减半。
- `try_quote` 返回 `inspection_prob`；worst_case 计入没收+罚款。

### 2.4 路线牌（夜 1 / 7 / 13 不可逆二选一，复用执照二选一控件）
- 夜1：**正规牌照**（官方进货 −8%、考核夜通过额外补贴 +$20）vs **灰道人脉**（走私品类 +1、走私价再 −5%）。（正规不再碰热度——修复激励倒挂）
- 夜7：**冷链协约**（保质期 +1、损耗费减半）vs **码头中介**（契约价 +10%、每夜 +1 张契约卡）。
- 夜13：**贵宾名录**（luxury/premium 需求 +25%）vs **缉私内线**（热度上限 50、查验概率 −40%）。
- 状态：`state.route_cards = {n1: id|null, n7: ..., n13: ...}`；`observation().route_offer` 仅在夜 1/7/13 非空。

### 2.5 黄昏访客（修复版深夜来客——原子性保住）
- 访客在**规划阶段**出现（`observation().visitor`），选择随 action 提交（`action.visitor = true/false`），try_step 内原子结算。每夜至多 1 位。
- **状态触发优先队列**（确定性，非随机；条件按序检查，首个命中者出现；均不命中且 stable_rng roll < 0.25 时出一位「串场客」纯风味小 offer 或不出）：
  1. 库存中今夜后将过期（days_left==1）批次 ≥4 件 → **收尾贩子·老盖**：以各品标价 55% 黄昏打包收走全部 days_left==1 批次（这些货不参加今晚销售）。落袋 vs 赌今晚卖原价。
  2. 热度 ≥40 → **缉私线人·三只手**：$12 + 热度×0.5 → 热度 −25。
  3. 明晚风声两候选概率差 ≤30 且现金 ≥$18 → **情报贩子·耳朵**：$18 → 明晚风声变确讯。
  4. 声望 ≥65 且 luxury/premium 库存 ≥2 → **豪客·九公主**：以 2× 标价买走至多 4 件奢侈品，条件：明晚为她保留 3 件同品（爽约 −3 声望，履约 +1 人情点）。保留承诺记 `state.vip_promise`。
- 结算位置：收尾贩子在散客销售**前**移出货并入账；其余即时生效。

### 2.6 回头客价格记忆
昨夜某品 价格/基准 ≥1.5 → 今夜该品需求 ×0.85；≤0.95 → ×1.06。UI 在定价行给小提示图标。状态：`state.price_memory = {pid: mult}`。

### 2.7 人情点（0–3）
- 获取：履约跨夜大单 +1、考核通过 +1、豪客履约 +1。
- 消耗（规划面板按钮，随 action 提交）：免除一次契约违约罚则 / 免今夜租金 / 成本价急补某品 5 件（无视行情）。
- 状态：`state.favor = int`。

### 2.8 债务与破产
- 现金可负，负现金每夜 20% 利息。
- 现金 <$30 可向**钱庄（老板娘：半两）**借 $150，其后 8 夜每夜还 $25，全季限 2 次。`state.loans = [...]`。
- **连续 3 夜结算净值（现金 + 库存×成本价×50% − 未还本金）< 0 → 破产结局「清算离港」**。`state.negative_streak`。

### 2.9 赛季弧线（18 夜 = 三幕 + 终夜）
- **一幕·立足**（1–6）租金 $12/夜。夜 6 **港务考核①**（夜 1 公示）：净值 ≥$260 → 补贴 $30 + 声望 +3 + 人情点 +1；未过 → 租金 +$6/夜直至考核②。
- **二幕·扩张**（7–12）租金 $22。跨夜大单解锁。夜 12 **考核②**：净值 ≥$700 且热度 <60 → 终夜摊位费半价 + 容量 +2；未过 → 终夜摊位费 ×1.5。
- **三幕·备战**（13–17）租金 $34。海关严查权重上升；**供应收口**：夜 16 进货 ×1.25、夜 17 ×1.5、**夜 18 批发市场关闭（不能进货）**——终夜只能卖囤下的货。
- **终夜·大离港**（18）摊位费 $50：demand_all ×2.2 + 主题 tag ×2.5，容量 +8。主题渐进揭示：夜 12 给 tag 域（「甜或闪」）→ 夜 15 收敛 + 终极大单 → 夜 17 确认。
- 事件表加 `phase_weights`（三幕各自权重）实现权重漂移。

### 2.10 终局与段位
- **终局分**（风险台账实时显示）= 现金 + 库存清算（成本 50%）− 未还债 ×1.5 + 声望 ×5 + 履约数 ×10 − 违约数 ×20 + 终极大单 150。
- 段位：≥2600 星港传奇 / ≥1900 轨道大亨 / ≥1300 码头老板 / ≥800 夜鹰 / ≥400 浮木 / 太空垃圾。传奇必须冒险，但必须是管理过的险。
- 里程碑保留为纯徽章（删 cash/rep 奖励）。

### 2.11 具名角色（纯 content.json 文案层）
六客群领队具名（码头工·铁砂 / 飞行员·候鸟 / 游客·小满 / 夜巡僧·无灯 / 废料商·斑鸠 / 豪客·九公主），访客与钱庄均有名字台词。事件 headline、访客 offer、结算 flavor 全部走 loc_zh.json。

## 3. 一夜流程

规划（备货屏）：① 看板（今晚事件+客群 / 明晚风声 / 后晚迷雾 / 风险台账：热度+查验率、债务、考核倒计时、终夜情报、终局分预估）→ ② 契约决断（≤2 张 + 到期大单倒计时）→ ③ 黄昏访客卡（若有，接/拒）→ ④ 进货（官方 per 品 + 走私舱卡）→ ⑤ 定价（回头客提示）→ ⑥ 夜 1/7/13 路线牌；升级（4 项）；人情点按钮 → ⑦ 计划面板「最好/最坏」两行净现金 → 开市。

结算（try_step 单次原子调用）：a) 访客结算（收尾贩子移货入账等）→ b) 查验判定 → c) 契约交付（优先扣库存，不足即违约触发罚则；人情点可预设抵消）→ d) 散客销售（需求管线 + 价格记忆）→ e) FIFO 损耗 → f) 租金/摊位费 + 利息 + 还款 → g) 热度衰减 → h) 声望结算 → i) 考核夜判定 → j) 净值与破产判定 → 报告。

## 4. 数值骨架

起手 $120、基础容量 26。租金合计 ≈$428。典型夜净利：一幕 $40–90 / 二幕 $80–180 / 三幕 $120–280（最差夜 ≈ −$80）/ 终夜 $250–600。升级 4 项：冷藏架（容量 +8，×2 级，$40/64）、情报天线（×2，$55/99）、保鲜封膜（×1，$70）、议价终端（×2，$50/85）。**全部数值进 content.json**（rent_curve、checkpoints、heat、contracts、visitors、finale、loans、score 权重全部表驱动）。

## 5. 平衡验证（实现必做）

`tools/balance_test.gd`（headless）：200 seed × 3 策略机器人：
- **保守**（不走私、只接现货单、稳价）目标破产率 <5%，均分 ~1000–1400；
- **均衡**（低热走私、选择性大单、押高概率风声）破产率 ~12%，均分 ~1700–2200；
- **贪婪**（满仓走私、全接契约、囤爆终夜）破产率 ~35%，但存活局均分应为三者最高。
另：检测退化策略——保守流若均分 ≥ 均衡流，判定失败需调参。输出分布报告。冒烟 smoke_test.gd 同步改写断言新机制。

## 6. UI 落点（对照重做后的 v3 界面）

- 顶部事件条 → 加「明晚风声」胶囊 + 后晚迷雾图标。
- 右栏自上而下：计划（含最好/最坏两行）→ 契约看板（≤2 卡 + 在身大单倒计时）→ 走私舱卡（2-3 行：图标+限量 stepper+价格+热度）→ 黄昏访客卡（有则显示）→ 升级/人情点行。执照区改为路线牌（仅 1/7/13 夜出现）。
- 新侧栏抽屉「风险台账」（唯一新面板）：热度表、查验率、债务、考核目标倒计时、终夜情报、终局分预估。快捷键 R。
- 结算屏账单加：契约收入/违约罚金/查验罚没/利息行；访客结果条。
- 终局屏账本加：履约/违约数、走私查获数、人情点、段位明账分解。

## 7. 接口扩展（只增不改）

- `observation()` 增：rumors、heat、inspection_prob、contracts（看板+在身）、visitor、route_offer、favor、debt、checkpoint、finale_intel、score_estimate、market_trend（近5夜行情）。
- `try_quote_action()` 增：best_case / worst_case / inspection_prob / contract_exposure。
- `action` 增：contracts_accept[]、smuggle{pid:qty}、visitor(bool)、route_card(id)、favor_use{type,pid}、loan(bool)。
- `terminal_summary()` 增：contracts_fulfilled/breached、seizures、ending 细分（completed / liquidated）。

## 8. 实现风险与降级

1. 走私批次 hot 标记贯穿 FIFO（售出/契约/损耗）——账目最易错，balance bot 加账目守恒断言（现金流每夜核对）。降级：查验只罚款不没收。
2. 跨夜大单状态机——active_contracts 到期/违约/定金流转。降级：首发仅现货急单 + 终极大单（保留终夜高潮）。
3. 数值死亡螺旋/形同虚设——全参数 content.json + balance bot 目标带校准。
4. 时长——新决策全部「看板→按钮」级；目标 ≤90 秒/夜、单局 ≤27 分钟。
